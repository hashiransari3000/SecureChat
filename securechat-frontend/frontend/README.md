# SecureChat frontend

React + Vite web application for SecureChat.

Run:

```bash
npm install
npm run dev
```

Open `http://localhost:5173` while the backend is running on port 5000. The API
base URL defaults to `http://localhost:5000` and can be overridden at build time
with `VITE_API_URL`. Modern Chromium/Edge/Firefox browsers are recommended for
Web Crypto, IndexedDB, notifications and microphone recording.

See the root [`README.md`](../../README.md) for the full quickstart.
