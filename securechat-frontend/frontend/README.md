# SecureChat frontend

React + Vite frontend for the SecureChat HCI/Data Ethics build.

Run:
```bat
npm install
npm run dev
```

Open `http://localhost:5173` while the backend is running on port 5000. Modern Chromium/Edge/Firefox browsers are recommended for Web Crypto, IndexedDB, notifications and microphone recording.

See `../../IMPLEMENTATION_GUIDE.md` for the full demo and E2EE boundary.
